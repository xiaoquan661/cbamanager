# 云函数部署指南（方案 A：HTTP 直读，约 30 分钟）

> ⚠️ 2026-10-29 更新：实际环境为「**Web 函数 / Nodejs 12.16**」，
> 请使用 **`relay/scf/index.web.js`**（Node12 兼容版，自带 HTTP 服务，监听 9001，零依赖）。
> `index.js`（事件函数 Node18 版）仅作存档，不要用它。

## 一、准备（5 分钟）

1. 注册/登录 [腾讯云](https://cloud.tencent.com)，实名认证
2. 搜索「**Serverless 云函数 SCF**」进入控制台（首次使用会提示开通服务层/角色授权，点同意，全部免费额度）

## 二、创建函数（10 分钟）—— 按你当前的 Web函数/Nodejs 12.16 环境走

1. 函数服务 → **新建**，配置：
   - 函数名称：`cba-relay`（现有 express_demo 直接改名复用也行）
   - 运行环境：**Nodejs 12.16**（已确认可用）
   - 函数类型：**Web 函数**
   - 内存：128MB 够用；超时时间：**60 秒**（重要！默认 3 秒不够拉 boxscore）
2. 函数代码：本地把 `relay/scf/index.web.js` **重命名为 `index.js`**（或删掉模板的 app.js 换成它）打包 zip 上传
   - 模板里若有 `package.json`（含 express），可以保留也可以删——本代码只用 Node 内置模块，不依赖任何包
   - 监听端口：代码默认 **9001**（腾讯云 Web 函数标准端口，无需改）
3. **函数 URL**（左侧「函数 URL 配置」）→ 开启，鉴权方式选「**无需鉴权**」，记下生成的 URL，形如：
   `https://1234567890-xxxx.ap-shanghai.tencentscf.com/`

## 三、验证（2 分钟）

浏览器直接访问（URL 后面拼路径）：
- `你的URL/cba/meta` → 应返回 `{"code":0,"data":{"season":"2026-2027","dates":[...]}}`
- `你的URL/cba/games?date=2026-10-28` → 应返回深铁 95:83 山西 + 23 人统计
- `你的URL/cba/players` → 球员+球队目录

如果报 502，看函数日志（控制台「日志查询」），把错误信息发我。

## 四、交付给我（1 分钟）

把你的函数 URL 发我，我接入游戏端（任务 #3）：游戏里三个请求会变成
- `${URL}/cba/meta`
- `${URL}/cba/players`
- `${URL}/cba/games?date=...`

## 五、注意事项

1. **费用**：SCF 免费额度 = 每月 100 万次调用 + 40 万 GB·s，本游戏用量连零头都不到，基本永久免费
2. **并发限制**：SCF 默认并发 20——玩家同时打开页面瞬间会排队，够用；量大后在「函数配置」调高
3. **缓存**：代码内置内存缓存（赛程 2 分钟 / 统计 5 分钟 / 目录 1 天），官方接口压力很小
4. **冷启动**：函数闲置几分钟后首次请求慢 1~2 秒，属正常
5. **安全**：无鉴权 URL 会公开——数据只有 CBA 公开赛果，无敏感信息，可接受

2. 桶开静态网站 + CDN，游戏改读静态 URL（延迟更低、官方接口零压力）
3. 到时候我把方案 B 的代码分支也写好，切换只是改游戏端一个 URL 配置
