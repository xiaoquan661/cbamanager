## 一、架构（最终形态）

```
CBA官方数据站（data-server.cbaleague.com，AES加密）
  ↓ 抓取+解密+格式化
用户云函数（腾讯SCF Web函数 Node12，relay/scf/index.web.js）
  ↓ https://1519902968-675a8dv0r8.ap-shanghai.tencentscf.com

  ↓ 驱动
身价浮动 / 每日预测开奖 / 状态层hot-cold-injured / 表现榜 / PVE对手数据
```

- Lamps 线上：走 `LampsGame.request`（平台规范）；本地调试：XHR（云函数已开 CORS）
- 每次启动：比对快照 `updatedAt`，只拉缺的日期（日常 1-3 天，秒级）；云函数内存缓存降低官方接口压力
- 失败自愈：请求级重试 3 次（冷启动 450）+ meta 失败 15 秒后整轮重跑；失败静默不影响游戏

## 二、调试中踩掉的坑（重要）

1. **云函数响应包了 `{code:0,data:{...}}` 一层**——游戏端取 `.dates` 必须先解包（表现为 meta 成功但静默返回空）
2. **meta 的 finishedCount 不可靠**（month 端点行结构缺 status）——改为 gameCount>0 即拉，完场判定交给 games 接口（day 端点 status 可靠）
3. **浏览器对无版本参数的子资源有缓存**——glue 引用已加 `?v=` 版本参数；以后每次改 glue 记得升版本号
4. SCF Web 函数：代码必须放 bootstrap 执行的入口文件（app.js），bootstrap 保持两行 shell；启动命令可在高级配置里直接指定
