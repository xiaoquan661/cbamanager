# 21 原版与新游戏对比表

> 原版：《CBA梦幻经理》虎扑线上最新版（r27-69，2026-10-27）
> 新游戏：《签下整个CBA》Lamps 版（基于原版 r27-37 深度改造）
> 更新：2026-10-30

## 一、平台与架构

| 维度 | 原版（虎扑） | 新游戏（签下整个CBA） |
|---|---|---|
| 平台 | 虎扑 AI 工坊（App 内 H5） | Lamps 小游戏 |
| 入口 | index.html → iframe → __ai_app.html | index.html 拍平直入 |
| 身份 | ColorboxAI 登录（必须虎扑账号） | Lamps 托管，无需登录 |
| 存档 | tcloudbase 服务器权威 | LampsPlatform 云存档 + localStorage 双写 |
| 广告 | vatask（虎扑） | LampsGame.showRewardedVideo（商店刷新/补给站） |
| 数据合规 | 虎扑防护/web-guard | 虎扑 SDK 痕迹清零 |

## 二、数据层（最大差异区）

| 维度 | 原版 | 新游戏 |
|---|---|---|
| 数据源 | 作者私有 tcloudbase（抓 CBA 官方加密接口） | **用户自建云函数**（同源破解，已验证逐字段一致） |
| 更新机制 | 整包快照，每次访问重拉（1MB+，几十秒） | **增量按日拉取 + localStorage 持久化，重载 8 秒恢复** |
| 容错 | 快照 fallback 本地 | 同 + 请求级 3 次重试 + 失败自动重跑 |
| 请求方式 | fetch（虎扑环境） | LampsGame.request（平台规范） |
