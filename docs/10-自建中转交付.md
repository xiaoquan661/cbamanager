## 一、破解成果（官方数据接口）

| 项 | 值 |
|---|---|
| API 主机 | `https://data-server.cbaleague.com` |
| 加密 | AES-128-ECB / PKCS7，密钥 `uVayqL4ONKjFbVzQ`（官方前端 JS 明文硬编码） |
| 请求头 | `isEncrypt: encrypt`（必需，否则 500/404） |

### 核心端点（全部实测 200 + 解密成功）
| 端点 | 方法 | 用途 |
|---|---|---|
| `/api/schedules/day?day=YYYY-MM-DD&auto=0` | GET | 当日赛程（status: 1未赛/2进行/4完场，isReport 标记） |
| `/api/player-match-datas/data-count` `{scheduleId}` | POST | **单场全部球员统计**（homeCounts/visitingCounts） |
| `/api/schedules/getPlayersByScheduleId/{id}` | GET | 每场报名名单（含 `isInjury` 伤停标记） |
| `/api/players/all` | GET | 全部球员目录 |
| `/api/teams/teamList` | GET | 球队列表 |
| `/api/schedules/month?year=&month=` | GET | 月度赛程 |

统计行字段：`playerId(官方ID)/gameStart(首发)/upTime(上场秒)/pts/reb/oreb/dreb/ast/stl/blk/turnovers/fouls/fg/ft/three/plusMinus`——**P1 状态层判定所需的 starter/min/DNP 数据全覆盖**。

## 三、部署方案（需要你做的）

1. **找台机器跑定时任务**（云函数/你的服务器/NAS 均可）：
   ```bash
   bun cba-relay.js day $(date +%F)        # 每日跑一次（建议 22:30 后，完场后）
   bun cba-relay.js meta <赛季首日> 120    # 每周跑一次，刷新日期索引
   ```
2. **把 `relay/out/` 目录发布到任意静态托管**（OSS/CDN/GitHub Pages/你的虚拟主机），三个地址即接口：
   - `players-catalog.json` → /cba/players（跑一次即可，`catalog` 命令）
   - `meta.json` → /cba/meta
   - `games-YYYY-MM-DD.json` → /cba/games?date=（游戏端按日期拼 URL）
3. 把托管域名给我 → 游戏端接入（任务 #3：glue 里把"内置快照"切到这三个 URL + 增量合并）

## 四、备注
- 抓取频率保持在每日个位数请求，温和限速 300ms/场
- 官方接口若改版：脚本 30 分钟内可修；游戏端有本地快照兜底，数据停更不影响可玩
- `catalog` 命令生成的目录含官方头像 URL，后续可给游戏换真实头像
