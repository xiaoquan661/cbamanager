# 04 M1 改造记录（去虎扑化 + Lamps 平台接入）

> 完成日期：2026-10-28。已实测（浏览器打开 index.html，进主界面、商店翻卡、存档写入、控制台零报错）。

## 改了什么

### 1. 结构拍平：`__ai_app.html` → `index.html`
- Lamps 要求根目录 `index.html` 为入口；原 `index.html` 只是虎扑外壳（iframe 套 `__ai_app.html`），中间层会隔断 Lamps bridge 的 postMessage 通道。
- 原 `index.html`（虎扑外壳）与 `__ai_app.html` 备份到 `docs/hupu-index-shell.html.bak`、`docs/hupu-entry-ai-app.html.bak`。
- 新 `index.html` 内容 = 原 `__ai_app.html`，并做以下移除：

| 移除项 | 位置 | 原因 |
|---|---|---|
| colyseus-0.18.2.js 外链 | 原 293 行 | 原版加载了但 0 次调用 |
| web-guard/2.0.27 外链 | 原 334 行 | 虎扑防护脚本 |
| colorbox-ai_v2.2.18.js 外链 | 原 346 行 | 虎扑 SDK；身份/存储由既有内联垫片覆盖 |
| cba-app-gate.js 引用 | 原 1107 行 | 虎扑 App 入口门槛；practice 模式本就绕过 |
| manifest 中 cba-startup.js 条目 | 原 1106 行 | 改由 glue 在云存档预载后加载（见 3） |

### 2. 注入 Lamps 四组 bridge/platform
`assets/lamps/`（来自平台 skill 规范，未改动）+ 新增 `cba-lamps-glue.js`：
- request-bridge / request-platform（`window.LampsGame.request`，M2 数据接口用）
- game-progress-bridge / game-progress-platform（`LampsPlatform.saveGameProgress/getGameProgress`）
- game-leaderboard-bridge / game-leaderboard-platform（M1-B 排行榜接入用）
- game-rewarded-video-bridge / game-rewarded-video-platform（激励视频）

### 3. 新增 `assets/lamps/cba-lamps-glue.js`（Lamps 接入层，核心）
1. **云存档镜像**：启动时 `getGameProgress()` 预载云端 practice 存档 → 提供同步适配器
   `window.CBA_LAMPS_STORAGE`（内存 → localStorage → Lamps 云端，写后 800ms 防抖推送，
   页面隐藏/关闭时立即推送）。存档体即 practice 存档原文，`{game_payload: <string>}`。
2. **bundle 加载**：`cba-startup.js` 在云存档预载完成后由 glue 注入（保证首启同步读档就能拿到云端进度）。
3. **广告垫片**：`ColorboxAI.vatask` → Lamps 激励视频：
   - `getActivityTaskState()` 恒回 `{code:200, tasks:[{taskCode:'reward',status:'pending'}]}`；
   - `completeRewardVideo()` → `LampsGame.showRewardedVideo({source:'shop-refresh'})`，
     仅 `res.ok===true` 发奖（转成游戏认识的 `{code:200,data:{rewarded:true}}`）；
   - 本地调试（UA 无 LampsSDK）直接发奖，保持单机可玩。
   游戏内所有 vatask 调用点（商店刷新、签到纪念卡）无需改动即被接管。

### 4. `cba-startup.js` 一行补丁（存档注入点）
会话工厂处 `localStorage: win.localStorage` → `win.CBA_LAMPS_STORAGE || win.localStorage`。
practice 会话的全部读写由此走适配器，其余 3.6MB 逻辑零改动。

### 5. 保留项（有意保留）
- `data-r13-practice="true"` 与 `CBAR13Practice` 本地存档层：它就是新游戏的存档核心（Lamps 版的"云"= LampsPlatform 镜像）。后续 M1-B 再处理徽章文案与「请先在虎扑 App 登录」提示。
- 访客身份垫片（`ColorboxAI.auth.getUserInfo` stub）：保留，避免身份模块超时重试。
