## 三、自建中转服务蓝图

```
定时脚本（每日/每赛完场）
  1. GET data-server.cbaleague.com/api/<端点>  ← 端点清单从官方前端 JS 枚举
  2. AES-128-ECB 解密（key 待抠）
  3. 转换成 01 文档的三个格式（/cba/players /cba/meta /cba/games?date=）
  4. 输出静态 JSON → 托管（云函数/OSS/任意主机）
```

### 待办（按序）
1. **抠 AES key**：拉取 www.cbaleague.com/data/ 的前端 JS，搜 AES/ECB/CryptoJS/decrypt 定位 key（128 位=16 字节字符串）
2. **枚举端点**：监听官方页面 Network，找赛程列表、比赛详情（gameReport）、球员名录对应的数据端点及参数
3. **写转换脚本**：官方明文结构 → 我们的 JSON schema（字段对照 player-feed.json，基本原样）
4. **定时+托管**：脚本完成后部署位置由用户定

### 额外收获
