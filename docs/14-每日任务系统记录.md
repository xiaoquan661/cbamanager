## 二、🐛 发放金额 bug —— 已修复（2026-10-29）

**真凶**（与最初猜测不同）：不是发错钱，也不是签到叠加——
- **practice 会话 dispatch 有动作白名单**，未知类型直接 throw"该功能需要正式云端账户"
- `taskClaim` 不在白名单 → dispatch 被拒 → **任务金币根本没发**
- 之前观察到的金币 500→1000 是**用户自己领取的每日签到 500**（签到第 1 天奖励就是 500），时间上巧合撞上领取测试，造成误判
- 另一个真 bug：glue 的 claimReward 无视 dispatch 返回值，把"已领取"记了下来（金币没到账但标记已领）

**修复**（三处）：
1. practice 白名单 Set 加入 `'taskClaim'`（dispatch → engine.reduce 走通）
2. claimReward 改为**先发奖后记标记**：`granted = dispatch(...)===true`，失败不记领取
3. claimWeekly 同样改造

**验证**（recon/test-taskclaim.js，可复用）：
- 白名单含 taskClaim ✓（精确锚点）
- 分支模拟：amount=20 → 500→520 ✓；amount=301 拒绝 ✓；amount=300 允许（周奖励）✓
- 浏览器 pane 不稳定，UI 层最终目验待浏览器恢复后做一次
